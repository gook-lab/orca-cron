# OrcaCron

Orca 에 떠 있는 Claude Code 터미널에 정해진 시각마다 작업을 보내는 macOS 메뉴 막대 앱입니다. 클라우드 예약이나 새 세션을 띄우는 대신, 지금 열어 둔 터미널에 그대로 한 줄을 넣어서 그 세션의 작업 폴더와 대화 맥락을 이어 씁니다. 터미널이 일하는 중이거나 사람이 입력 중이면 빌 때까지 기다렸다가 보냅니다.

Orca 의 공식 도구가 아니라 개인이 만든 보조 앱입니다. Orca 에 들어 있는 CLI(`orca terminal …`)만 사용합니다.

## 설치 — 에이전트에게 링크로

Claude Code·Codex 에게 "https://github.com/gook-lab/orca-cron/blob/main/INSTALL.md 보고 설치해줘"라고 하면 됩니다. 절차와 막히는 곳은 [INSTALL.md](INSTALL.md), 버전별 변경 내용은 [CHANGELOG.md](CHANGELOG.md) 에 있습니다.

## 빌드 · 설치 — swift build 단일 스크립트

Xcode 없이 Command Line Tools 의 Swift 6 으로 빌드합니다(macOS 15 이상).

```bash
./build.sh            # build/OrcaCron.app (이 맥 아키텍처)
./build.sh install    # ~/Applications 로 복사하고 launchd(lab.gook.orcacron)에 올림 — 로그인 때 자동 실행
```

빌드할 때마다 판정 규칙 점검(`SchedulerCheck`, 135개)을 돌리고, 하나라도 실패하면 설치하지 않습니다. Command Line Tools 에는 XCTest 가 없어서 점검을 실행 파일로 만들었습니다.

Dock 아이콘 없이 메뉴 막대에만 상주합니다. 메뉴의 「종료」로 끄면 다음 로그인까지 꺼진 채로 있고, 비정상 종료는 launchd 가 다시 띄웁니다.

## 화면 구성 — 메뉴 막대 · 팝업 · 창

- 메뉴 막대: 시계 아이콘. 대기가 길어졌거나 실패한 예약이 있으면 느낌표가 붙습니다.
- 팝업(폭 400): 머리 줄에 로고와 다음 실행을 두고, 예약이 있는 터미널을 위에, 예약 없는 터미널을 아래에 둡니다. 예약 없는 터미널은 처음 4개만 보이고 「더 보기」로 펼칩니다. 터미널 묶음 머리 줄을 누르면 접히고, 끝난 「한 번 보내기」는 「보낸 기록 N」으로 접힙니다. 예약 줄의 이름을 누르면 편집으로 들어갑니다.
- 머리 줄 오른쪽에 버전·업데이트 상태가 늘 보입니다. 새 커밋이 있으면 「업데이트 N」(누르면 설치), 없으면 「v1.N ✓」(누르면 다시 확인)입니다.
- 메뉴 막대 아이콘은 템플릿 이미지라 밝은·어두운 막대에 맞춰 색이 바뀌고, 팝업도 시스템 테마를 따릅니다.
- 창: ⋯ 메뉴의 「창으로 열기」. 크기를 바꿀 수 있는 창으로 같은 화면을 엽니다. 아이콘은 처음 켤 때 배터리 아이콘 바로 왼쪽에 자리 잡아 노치에 가려지지 않습니다(⌘ 를 누른 채 끌어 옮기면 그 자리를 기억합니다). 앱을 실행하면(Spotlight·Finder·`open ~/Applications/OrcaCron.app`) 마우스가 있는 화면의 아이콘 아래에 팝업이 열립니다. 아이콘이 노치에 가려졌으면 팝업 대신 창으로 엽니다. 로그인 때 launchd 가 띄울 때는 아무것도 열지 않습니다.

| 화면 | 누르는 곳 → 가는 곳 |

## 예약 · 보내기 · 템플릿 — 메뉴에서 하는 일

| 기능 | 하는 일 |
|---|---|
| 예약 | 터미널 · 내용(템플릿 또는 직접 입력) · 시각으로 반복 실행. 시각 = 요일(매일·평일·휴일(토·일)·요일 고르기) 또는 「날짜 지정」(달력에서 날을 여러 개 고름, 그해 그날에만) + 「정한 시각」(「추가」로 칸을 늘림, 09:30 · 18:00 처럼 분이 달라도 됨) 또는 「반복」(N분마다, 종일 또는 07:00~08:00 같은 구간 · 끝 시각 포함). 시각 칸은 `0730` · `7:30` · `7시 30분` 처럼 바로 침. 다른 모양은 「cron 직접」(여섯째 칸을 쓰면 연도: `0 9 20 11 * 2026`) |
| 보내기 | 시각 없이 지금 한 번. 전송 조건은 예약과 같음. 결과 받기를 켜면 결과도 목록에 남음 |
| 템플릿 | `tasks/*.md` 를 메뉴에서 만들고 고침. 검색 · 할당(예약 만들기) · 보내기. 예약·보내기 화면의 템플릿 칸 옆 ✎·+ 로 바로 고치거나 만듦. 예약이 쓰는 템플릿은 삭제 불가 |
| 지금 실행 | 예약 줄의 ▶. 시각을 기다리지 않고 다음 확인(30초 안)에 대기열로 |
| 연결 시험 | 보내기 화면의 「연결 시험 보내기」 또는 터미널 줄 우클릭. 받는 Claude 가 결과 명령까지 실행하면 「성공 · 연결 시험 통과」가 남음 |
| 새 대화 | 예약 편집의 「보내기 전에 대화 비우기」. `/clear` 를 먼저 보내고 화면이 다시 조용해지면 본문을 보냄. 그 터미널의 대화가 지워지니 예약 전용 터미널에만 |

## Claude 명령 — / 자동완성 · 두 가지 보내는 방식

입력 칸(예약·보내기의 직접 입력, 템플릿 본문)에서 `/` 를 치면 받는 터미널에서 쓸 수 있는 명령·스킬이 뜹니다. ↑↓ 로 고르고 tab·return 으로 넣거나 마우스로 누르며, esc 는 후보만 닫습니다(후보가 없을 때의 esc 는 취소). 후보가 여섯 개를 넘으면 목록 안에서 스크롤되고, 타자가 80ms 멈추면 다시 찾습니다(디바운스). 「/ 명령 넣기」로 검색해서 고를 수도 있고, 그 창도 ↑↓·return 으로 고릅니다. 목록은 Claude Code 가 읽는 폴더와 같은 곳에서 모읍니다 — 개인 `~/.claude/{commands,skills}`, 받는 터미널 작업 폴더의 `.claude/{commands,skills}`, 켜진 플러그인, 자주 쓰는 내장 명령.

| 쓰는 곳 | 보내는 방식 | 결과 받기 |
|---|---|---|
| 직접 입력이 `/` 로 시작 | 글 그대로 보냄 — 받는 Claude Code 가 명령으로 실행. 내장 명령·잠긴 스킬도 됨 | 안 됨(결과 명령을 같은 줄에 붙일 수 없음) |
| 템플릿 본문에 「/스킬 을 실행한다」 | 받는 Claude 가 파일을 읽고 스킬 도구로 실행 | 됨. 단 내장 명령·잠긴 스킬(🔒)은 실행되지 않아 편집 화면에 경고 |

## 전송 조건 — 터미널이 비었을 때만

30초마다 확인하고, 시각이 된 예약은 대기에 올린 뒤 아래가 모두 맞을 때 보냅니다.

1. 그 터미널이 Orca 에 살아 있습니다. Orca 를 다시 켜서 터미널 핸들이 바뀌어도 같은 탭이면 자동으로 다시 연결합니다. 탭이 사라졌으면 「건너뜀」으로 남기고, 편집에서 터미널을 다시 고르면 됩니다.
2. 화면이 「조용한 시간」(기본 1분, ⋯ 메뉴에서 1·3·5·10분) 동안 움직이지 않았습니다. 키를 치면 화면 출력 시각이 바로 갱신되므로 입력 중인 터미널에는 보내지 않습니다.
3. `orca terminal wait --for tui-idle` 이 만족하고, 화면 끝에 입력 칸(가로줄 아래 `❯`, 버전에 따라 `›`·`>`)이 보입니다. 질문·권한 창이 떠 있으면 기다립니다.
4. 같은 터미널에 이전 실행의 결과가 아직 안 왔으면 기다립니다.

60분을 기다려도 조건이 안 맞으면 「건너뜀」으로 남깁니다. 꺼 둔 동안 지난 시각은 다시 켜도 바로 돌지 않습니다.

Claude Code 가 화면 모양을 바꾸면 입력 칸을 못 찾아 계속 건너뛸 수 있습니다. 24시간 안에 「입력 칸이 보이지 않음」으로 두 번 건너뛰면 머리 줄과 알림으로 알립니다. 그때 ⋯ 메뉴 「화면 진단 저장」을 누르면 터미널마다 판정 결과와 화면 끝 15줄이 `~/.orca-cron/diagnose-*.txt` 로 남습니다(화면 내용이 그대로 들어가니 공유 전에 확인해 주세요).

## 결과 대기 중 멈춤 · 알림 · 늦은 실행

- 결과를 기다리는 동안 30초마다 그 터미널을 봅니다. 권한 확인 창에 멈췄거나, 질문·선택 창이 떠 있거나, 끝났는데 3분 넘게 결과 명령을 부르지 않았으면 예약 줄에 주황색으로 이유를 적고 메뉴 막대 아이콘에 느낌표를 붙입니다.
- 실패 · 결과 없음 · 건너뜀 · 멈춤 · 새 업데이트는 macOS 알림으로도 알립니다. ⋯ 메뉴 「알림」에서 「끝날 때마다(성공 포함)」나 「끄기」로 바꿀 수 있습니다. 직접 빌드한 앱이라 알림 이름은 「스크립트 편집기」로 보입니다.
- 보낼 예약이 대기 중이거나 결과를 기다리는 동안(보낸 지 2시간 안) 맥이 저절로 잠들지 않게 합니다. 화면은 꺼질 수 있고, 덮개를 닫으면 막지 못합니다.
- 맥이 잠들었거나 앱이 꺼진 동안 지나간 시각은 깨어난 뒤 한 번 보냅니다(여러 번 지나갔어도 한 번). 예약 편집의 「늦으면」에서 30분·1·3·6시간 넘게 늦으면 건너뛰도록 고를 수 있습니다.
- 예약 줄의 「기록」을 누르면 기록이 있는 가장 최근 날의 시각 · 결과 · 요약 · 링크가 10개씩 펼쳐집니다. 날짜 칸에서 다른 날을 고르고, ‹ › 로 기록이 있는 앞뒤 날로, 오른쪽 ‹ › 로 그날의 다음 10개로 넘깁니다. 기록은 30일 동안 남습니다.

받는 Claude Code 가 결과 명령을 매번 묻지 않게 하려면 `~/.claude/settings.json` 의 `permissions.allow` 에 아래 규칙을 넣어 주세요. ⋯ 메뉴 「결과 명령 허용 규칙 복사」가 이 줄을 복사합니다.

```json
"Bash(/Users/<사용자>/Applications/OrcaCron.app/Contents/MacOS/OrcaCron finish:*)"
```

## 결과 기록 — finish 명령

결과 받기가 켜진 전송은 보내는 문장 끝에 결과를 남기는 명령이 붙습니다. 터미널 쪽 Claude 가 작업을 마치고 이 명령을 실행하면 메뉴에 30초 안에 반영됩니다. 보낸 뒤 6시간 안에 결과가 안 오면 「결과 없음」으로 닫습니다.

```bash
~/Applications/OrcaCron.app/Contents/MacOS/OrcaCron finish --run <run id> --status 성공|실패|건너뜀 --summary "한 줄 요약" [--link URL]
~/Applications/OrcaCron.app/Contents/MacOS/OrcaCron status                    # 예약 목록
~/Applications/OrcaCron.app/Contents/MacOS/OrcaCron preview out.png [templates] # 화면을 PNG 로(보내지 않음). ORCA_CRON_APPEARANCE=light|dark 로 테마 지정
```

## 명령줄 보내기 — send · test

앱의 「보내기」와 같은 한 번 보내기를 명령줄에서 남깁니다. 요청은 `~/.orca-cron/inbox/` 에 쓰이고, 떠 있는 앱이 바로 받아 같은 전송 조건으로 보냅니다.

```bash
OrcaCron send                                              # --terminal 없이: 떠 있는 Claude Code 터미널 목록
OrcaCron send --terminal <핸들> --text "할 일" [--track] [--name "이름"]
OrcaCron send --terminal <핸들> --template <키> [--track]
OrcaCron test --terminal <핸들>                             # 연결 시험(결과 받기 켬)
```

## 데이터 폴더 — ~/.orca-cron

셸 명령에 그대로 넣을 수 있게 공백 없는 경로를 씁니다. `ORCA_CRON_HOME` 으로 바꿀 수 있습니다.

| 경로 | 내용 |
|---|---|
| `schedules.json` | 예약 목록. 앱이 유일하게 씀(앱이 도는 동안 손으로 고치면 덮어씀) |
| `tasks/<키>.md` | 템플릿. 첫 줄 `# 제목`, 둘째 줄 한 줄 설명, 빈 줄 뒤 본문 |
| `results/` | 터미널 쪽 세션이 남긴 결과. 앱이 읽고 지움 |
| `inbox/` | `OrcaCron send`·`test` 요청. 앱이 읽고 지움 |
| `diagnose-*.txt` | 「화면 진단 저장」 결과. 화면 내용이 들어 있음 |
| `history/<예약 id>.jsonl` | 예약마다 실행 결과 한 줄씩(30일). 「기록」 화면이 읽음. 지운 예약의 파일은 하루 뒤 앱을 켤 때 지움 |
| `log.txt` | 보냄 · 결과 · 건너뜀 · 다시 연결 기록 |

## 입력 칸에 쳐 둔 글 — 알려진 한계

Orca 의 화면 읽기에는 사람이 입력 칸에 쳐 둔 글이 보이지 않습니다(2026-11-11 실측). 그래서 화면 출력 시각으로 입력 중인지를 판단합니다. 글을 써 두고 「조용한 시간」보다 오래 자리를 비우면, 그 글 뒤에 예약 문장이 붙어 함께 보내질 수 있습니다. 이런 일이 잦으면 ⋯ 메뉴 「조용한 시간」을 5·10분으로 늘리거나, 예약은 사람이 쓰지 않는 전용 터미널에 거세요.
